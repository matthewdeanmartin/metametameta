01 / THE WORKFLOW

Write metadata once.
Use it where you need it.

Many projects keep version and author details in a project configuration, but also expose dunder variables in a Python module. metametameta connects the two.

01
⌕

Point to a known format, or use auto to detect a single viable metadata source. Ambiguous projects need an explicit choice.

02 / WORKING EXAMPLES

One command per source.

Choose the command that matches how your project declares its metadata. These examples run in your project root.

project root / terminalCLI

# PEP 621 [project] in pyproject.toml

$ metametameta pep621

# Let the tool detect one metadata source

$ metametameta auto

# Compare generated metadata with its source

$ metametameta sync-check

04 / GOOD TO KNOW

Metadata can be messy.

Dunder metadata is a convention, not a universal standard. Projects differ in where they store it and which values they expose. Choose your source explicitly when automatic discovery finds more than one candidate, and review generated output before shipping.
